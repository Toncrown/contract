Functions
User Registration and Referral System
receive(msg: Register)
Registers a new user. If a referrer is provided, the referral system is updated.

REACT INTEGRATION:
Use a form to collect the user's address and optional referrer address. Call this function via a transaction.

fun processReferralRegistration(newUser: Address, referrer: Address)
Handles referral logic for new users.

Level Upgrade System
receive(msg: UpgradeLevel)
Allows users to upgrade their level sequentially by paying the required TON amount.
React Integration:
Display the user's current level and the cost for the next level. Trigger this function when the user clicks "Upgrade Level."

fun calculateVipClass(level: Int): Int
Determines the VIP class based on the user's level.

Staking System
receive(msg: StakeTON)
Allows VIP users to stake TON tokens for rewards.
React Integration:
Provide a form to input staking duration and auto-restake preference. Call this function via a transaction.

receive(msg: ClaimStakingRewards)
Allows users to claim staking rewards.
React Integration:
Add a "Claim Rewards" button that triggers this function.

receive(msg: UnstakeTON)
Allows users to unstake their tokens.
React Integration:
Add an "Unstake" button that triggers this function.

Reward Distribution
receive(msg: CheckIn)
Allows users to check in daily for rewards.
React Integration:
Add a "Daily Check-In" button that triggers this function.

receive(msg: ClaimPendingRewards)
Allows users to claim pending rewards.
React Integration:
